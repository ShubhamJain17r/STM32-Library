# I2C (Inter-Integrated Circuit) Subsystem Documentation

## 1. Peripheral Overview (STM32F446RE)

The STM32F446RE contains **3 hardware I2C** modules (`I2C1`, `I2C2`, `I2C3`):
* **Bus Architecture**:
  * All 3 I2C peripherals operate on **APB1** (up to 45 MHz bus clock).
* **Speed Profiles**:
  * **Standard Mode (Sm)**: Up to **100 kHz** ($T_{\text{low}} = T_{\text{high}} = 5\mu\text{s}$, maximum rise time $1000\text{ ns}$).
  * **Fast Mode (Fm)**: Up to **400 kHz** ($T_{\text{low}} = 2 \times T_{\text{high}}$ at Duty 2:1, maximum rise time $300\text{ ns}$).
* **Hardware Capabilities**:
  * 7-bit and 10-bit slave addressing.
  * Multi-master and SMBus 2.0 / PMBus support.
  * Clock stretching and dual addressing (`OAR2`).
  * Hardware packet error checking (PEC).
  * Comprehensive error detection (BERR, ARLO, AF, OVR, TIMEOUT).

## 3. Architecture & Directory Layout

```

├── core/
│   ├── i2c_types.hpp          <-- Enums: Instance, Speed, DutyCycle, AddressingMode, I2cStatus

├── interrupt/
│   ├── i2c_interrupt.hpp      <-- Event and error callback dispatch table

│   └── i2c_irq.cpp            <-- ISR vector handlers (I2C1_EV/ER..I2C3_EV/ER)
└── i2c.hpp                    <-- Master umbrella header
```

## 5. API Reference

### `i2c::I2cMaster<Instance>`
```cpp
namespace i2c
{
    template<Instance I>
    class I2cMaster
    {
    public:
        explicit I2cMaster(std::uint32_t speedHz = 100'000);
        explicit I2cMaster(gpio::Pin scl, gpio::Pin sda, std::uint32_t speedHz = 100'000);
        explicit I2cMaster(const I2cConfig<I>& config);

        // Master Write & Read
        bool write(std::uint8_t devAddr, const std::uint8_t* data, std::size_t length, bool sendStop = true, std::uint32_t timeoutMs = 50) noexcept;
        bool write(std::uint8_t devAddr, std::uint8_t byte, bool sendStop = true, std::uint32_t timeoutMs = 50) noexcept;

        bool read(std::uint8_t devAddr, std::uint8_t* data, std::size_t length, std::uint32_t timeoutMs = 50) noexcept;
        bool read(std::uint8_t devAddr, std::uint8_t& byte, std::uint32_t timeoutMs = 50) noexcept;

        // Register-Level Sensor Read / Write Helpers
        bool writeRegister(std::uint8_t devAddr, std::uint8_t regAddr, std::uint8_t value, std::uint32_t timeoutMs = 50) noexcept;
        bool writeRegister(std::uint8_t devAddr, std::uint8_t regAddr, const std::uint8_t* data, std::size_t length, std::uint32_t timeoutMs = 50) noexcept;
        bool writeRegister16(std::uint8_t devAddr, std::uint16_t regAddr, const std::uint8_t* data, std::size_t length, std::uint32_t timeoutMs = 50) noexcept;

        bool readRegister(std::uint8_t devAddr, std::uint8_t regAddr, std::uint8_t& value, std::uint32_t timeoutMs = 50) noexcept;
        bool readRegister(std::uint8_t devAddr, std::uint8_t regAddr, std::uint8_t* data, std::size_t length, std::uint32_t timeoutMs = 50) noexcept;
        bool readRegister16(std::uint8_t devAddr, std::uint16_t regAddr, std::uint8_t* data, std::size_t length, std::uint32_t timeoutMs = 50) noexcept;

        // Bus Health & Utilities
        bool isDeviceReady(std::uint8_t address, std::uint32_t trials = 2, std::uint32_t timeoutMs = 25) noexcept;
        std::size_t scanBus(std::uint8_t* foundAddresses, std::size_t maxCount) noexcept;
        bool recoverBus() noexcept;

        I2cStatus getLastError() const noexcept;
    };

    using I2c1 = I2cMaster<Instance::i2c1>;
    using I2c2 = I2cMaster<Instance::i2c2>;
    using I2c3 = I2cMaster<Instance::i2c3>;
}
```

## 6. Usage Examples

### Example 1: I2C Bus Scanner
```cpp
#include "stm32/i2c/i2c.hpp"
#include "stm32/uart/uart.hpp"

using namespace i2c;
using namespace uart;

int main()
{
    Uart2 serial(115200);
    I2c1 i2c(100'000); // 100 kHz on PB8 (SCL), PB9 (SDA)

    std::uint8_t devices[16];
    std::size_t count = i2c.scanBus(devices, 16);

    for(std::size_t i = 0; i < count; ++i)
    {
        // Device found at devices[i]
    }

    while(true) {}
}
```

### Example 2: Reading Sensor Register (e.g. MPU6050 WHO_AM_I)
```cpp
#include "stm32/i2c/i2c.hpp"

using namespace i2c;

int main()
{
    I2c1 i2c(400'000); // 400 kHz Fast Mode

    constexpr std::uint8_t MPU6050_ADDR = 0x68;
    constexpr std::uint8_t WHO_AM_I_REG = 0x75;

    std::uint8_t chipId = 0;
    if(i2c.readRegister(MPU6050_ADDR, WHO_AM_I_REG, chipId))
    {
        // chipId will equal 0x68
    }

    while(true) {}
}
```
